# 신규 계산기 카테고리 3종 추가 — 부동산 / 자동차 / 건강·생활

## Context

기존 7개 그룹(주식·저축·직장인·나이·대출·날짜·셀러)은 재테크·직장 관련 위주였고,
부동산·자동차·건강 같은 생활 밀착형 검색 카테고리가 비어 있었다. SEO 검색량이 크고
기존 세금 계산기(프리랜서 3.3%, 셀러 부가세 등)와 구현 패턴이 통하는 부동산 세금부터
우선 다룬다. 이번 스코프는 3개 그룹, 총 7개 계산기.

## 그룹 및 계산기 목록

`src/App.tsx`의 `GROUP_ORDER`에 `'부동산'`, `'자동차'`, `'건강'`을 새 그룹으로 추가한다
(순서는 기존 뒤에 이어 붙임: `[...기존, '부동산', '자동차', '건강']`).

### 부동산 (3개)

| id | path | label | 설명 |
|---|---|---|---|
| `acquisitionTax` | `/acquisition-tax` | 취득세 | 주택 유상취득세 — 주택가액·보유주택수·조정대상지역 여부·전용면적(85㎡ 기준)으로 취득세+지방교육세+농특세 계산 |
| `propertyTax` | `/property-tax` | 재산세 | 공시가격 기준 재산세(누진 구간) + 도시지역분, 1세대1주택 특례세율(공시 9억 이하) 반영 |
| `comprehensiveRealEstateTax` | `/comprehensive-real-estate-tax` | 종합부동산세 | 인별 공시가격 합산액 기준, 1세대1주택자 기본공제(12억) vs 다주택자 기본공제(9억) 구분, 세부담 상한 언급 |

**취득세 세율 구조 (설계 기준안, 구현 시 위택스 최신 고시로 재검증):**
- 1주택(또는 일시적 2주택): 6억 이하 1%, 6억 초과~9억 이하 구간별 선형 보간(1~3%), 9억 초과 3%
- 2주택: 비조정지역 1~3%(1주택과 동일), 조정대상지역 8%
- 3주택 이상: 비조정 8%, 조정 12% / 법인·4주택 이상은 12% 고정
- 지방교육세: 취득세율 초과분 기준 근사(취득세액의 10%), 농특세: 전용 85㎡ 초과 시 0.2%
- 결과 화면에 "위택스 기준 시뮬레이션이며 실제 신고 세액은 지자체 고지액과 다를 수 있음" 디스클레이머 (기존 계산기들의 톤과 동일)

**재산세:** 공시가격 × 공정시장가액비율(주택 60%, 1주택자 특례 43~45%) × 누진세율(0.1%~0.4%, 4구간) − 누진공제 + 도시지역분(0.14%) + 지방교육세(재산세의 20%)

**종부세:** (공시가격 합산 − 기본공제) × 공정시장가액비율(60%) × 누진세율(0.5%~5%, 다주택 중과 구간 포함) − 누진공제 − 재산세 중복분 공제(간이 근사), 세부담상한 문구만 안내(정밀 계산은 생략)

## 구현 패턴 (기존 컨벤션 그대로 적용)

각 계산기는 기존 코드베이스 패턴을 그대로 따른다 — 새 아키텍처 없음:

1. **계산 로직**: `src/lib/<name>.ts` — 순수 함수, 기존 `freelanceTax.ts`/`bizTax.ts`/`loan.ts` 스타일
2. **페이지**: `src/pages/<Name>Calculator.tsx` — `Field`/`Row`/`fmt` 공용 UI 컴포넌트 사용, 결과 카드 + 안내/디스클레이머 박스 (`FreelanceTaxCalculator.tsx` 참고)
3. **라우트**: `src/routes.json`에 `id`/`path`/`label`/`group`/`title`/`description` 추가
4. **코드 스플리팅**: `src/App.tsx`의 `components` 맵에 `lazy(() => import(...))` 항목 추가, `GROUP_ORDER`에 3개 그룹 추가
5. **SEO 콘텐츠**: `src/lib/pageContent.js`에 각 계산기의 `intro`(1~2문단) + `faqs`(2~3개) 추가 — 프리렌더용
6. **README**: 이미 구축된 `scripts/update-readme.mjs` + PostToolUse 훅이 `routes.json` 수정 시 자동 갱신하므로 별도 작업 불필요

**테스트**: 기존 프로젝트에 단위 테스트가 전혀 없음(컨벤션 확인됨) — 이번에도 추가하지 않고 기존 스타일을 따름. 대신 `npm run build`로 타입체크 + `postbuild.mjs` 정상 동작(정적 페이지 생성)을 확인.
